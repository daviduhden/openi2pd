# x25519

Generate an X25519 key pair for encrypted LeaseSet authentication.

## Syntax

```sh
x25519 [--help]
```

Prints `PublicKey:` and `PrivateKey:` in I2P base64.

## Example

```sh
x25519
```

Server-side tunnel configuration:

```ini
signaturetype = 11
i2cp.leaseSetType = 5
i2cp.leaseSetAuthType = 1
i2cp.leaseSetClient.dh.210 = clientName:PublicKey
```

Client-side:

```ini
i2cp.leaseSetPrivKey = PrivateKey
```

## Security

The private key is printed to stdout and the tool wipes its copy before exit.
Use `umask 077` for any redirection and keep the client key secret.

## Compatibility

Uses OpenSSL's X25519 implementation. The encodings are the raw 32-byte keys in
I2P base64, as expected by the encrypted LeaseSet specification.
