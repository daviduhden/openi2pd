# History

openi2pd continues the C++ I2P router lineage of i2pd while maintaining a
separate release identity and architecture. The maintained tree uses C++23,
CMake as the primary build system, native ncursesw and Win32 interfaces, and a
bounded Android Material implementation.

The fork deliberately omits the historical browser administration console,
GNU make build path and external web assets. Protocol and configuration
identifiers remain compatible where documented; imported upstream material and
its notices are recorded in [`../upstream-sync.md`](../upstream-sync.md) and the
attribution audit.
